Resources {% id="resources" %} ### FileSearchStore {% id="Resource:FileSearchStore" %} A [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore) is a collection of `Document`s. **Properties:** {% section class="api-ref-property-list" %} **name**: `string` Output only. Immutable. Identifier. The [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore) resource name. It is an ID (name excluding the "fileSearchStores/" prefix) that can contain up to 40 characters that are lowercase alphanumeric or dashes (-). It is output only. The unique name will be derived from `display_name` along with a 12 character random suffix. Example: `fileSearchStores/my-awesome-file-search-store-123a456b789c` If `display_name` is not provided, the name will be randomly generated. {% hr /%} **displayName**: `string` Optional. The human-readable display name for the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore). The display name must be no more than 512 characters in length, including spaces. Example: "Docs on Semantic Retriever" {% hr /%} **createTime**: `string` Output only. The Timestamp of when the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore) was created. {% hr /%} **updateTime**: `string` Output only. The Timestamp of when the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore) was last updated. {% hr /%} **activeDocumentsCount**: `string` Output only. The number of documents in the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore) that are active and ready for retrieval. {% hr /%} **pendingDocumentsCount**: `string` Output only. The number of documents in the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore) that are being processed. {% hr /%} **failedDocumentsCount**: `string` Output only. The number of documents in the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore) that have failed processing. {% hr /%} **sizeBytes**: `string` Output only. The size of raw bytes ingested into the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore). This is the total size of all the documents in the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore). {% hr /%} **embeddingModel**: `string` Optional. The embedding model to use for the [`FileSearchStore`](/api-reference/file-search/file-search-stores#Resource:FileSearchStore). The model's resource name. This serves as an ID for the Model to use. Format: `models/{model}`. If not specified, the default embedding model will be used. {% /section %}
