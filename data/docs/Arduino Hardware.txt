# UNO Q

The Arduino UNO Q unlocks a new level of performance for the Arduino ecosystem, blending robust computing power from Qualcomm's advanced Dragonwing™ QRB2210 MPU running a full Debian Linux OS with upstream support, and the real-time responsiveness of a dedicated STM32U585 MCU running Arduino sketches over Zephyr OS - all on a single-board computer.

[User Manual](/tutorials/uno-q/user-manual)[Arduino App Lab](/software/app-lab/getting-started/quickstart/)

Pinout

[Buy now](https://store.arduino.cc/pages/uno-q)

[Schematics](/resources/schematics/ABX00162-schematics.pdf)[CAD Files](/static/e05d1a3141208468509d10c329387dcd/ABX00162-cad-files.zip)[STEP Files](/resources/models/ABX00162-step.zip)

Features

Tech Specs

Compatibility

Suggested Libraries

The **Arduino® UNO Q** integrates the Qualcomm® QRB2210 Microprocessor (MPU), running a full Debian-based Linux environment, with the STMicroelectronics® STM32U585 Microcontroller (MCU) built on Arm® Cortex®-M33 architecture, all within the compact UNO form factor. This dual-architecture platform combines high-performance computing with deterministic real-time control, delivering the power and versatility needed for modern AI at the edge applications.

Unlock hybrid development with Arduino App Lab, seamlessly uniting Python applications, Arduino sketches, and AI models in a single workflow. From AI-powered vision and sound solutions that react intelligently to their environment to sophisticated smart home systems, UNO Q with Arduino App Lab delivers next-generation embedded innovation to makers, educators, and professionals alike. At the same time, developers enjoy true freedom of choice: program the MCU subsystem with the Arduino IDE, or integrate Arduino CLI into existing workflows with popular editors like VS Code.

Qualcomm Dragonwing™ QRB2210

Includes the powerful Qualcomm Dragonwing™ QRB2210 processor featuring:

  * Quad-core Arm® Cortex®-A53 @ 2.0 GHz
  * Adreno GPU 3D graphics accelerator
  * 2x ISP (13 MP + 13 MP or 25 MP) @ 30 fps



[Overview](https://www.qualcomm.com/products/internet-of-things/robotics-processors/qrb2210)

STM32U585 Arm® Cortex®-M33 32-bit MCU

The UNO Q integrates the STM32U585 microcontroller featuring:

  * Arm® Cortex®-M33 up to 160 MHz
  * 2 MB flash memory
  * 786 kB SRAM
  * Floating Point Unit



[Datasheet](https://www.st.com/resource/en/datasheet/stm32u585ai.pdf)

Single-Board Computer

You can use the UNO Q as a standalone single-board computer leveraging its built-in **Debian Linux environment**. By using a USB-C dongle with external power delivery connected to the UNO Q USB-C port, you can connect:

  * HDMI display
  * Mouse and keyboard
  * USB camera
  * USB drive


  * Ethernet cable
  * microSD card
  * USB microphone
  * USB headphones



**Note:** Recommended with the **4 GB RAM** UNO Q variant.

Debian Linux OS

The Arduino UNO Q features a built-in **Debian Linux** environment with upstream support powered by its high-performance application processor, allowing you to develop in a familiar Linux environment without additional hardware.

Wireless Connectivity

The WCBN3536A wireless module allows to simultaneously manage WiFi® and Bluetooth® connectivity. The module features:

  * **Wi-Fi® 5** Dual-band (2.4/5 GHz) with onboard antenna
  * **Bluetooth® 5.1** with onboard antenna



Easily Expandable

Take the UNO Q even further with its expandability leveraging the following features:

  * **Qwiic connector** for seamless compatibility with Modulino nodes
  * **Traditional UNO headers** allowing you to stack official or custom shields on top of the UNO Q
  * **New bottom high-speed connectors** for using carriers to connect MIPI-CSI cameras, MIPI-DSI displays, analog audio, and much more



Multiple IDE Compatibility

The UNO Q is designed for flexible development, with first-class support for the **Arduino App Lab** and compatibility with the latest **Arduino IDE 2.0+**.

  * **Arduino App Lab** – Develop for both the onboard MPU and MCU with ease. Recommended for a full development experience.
  * **Arduino IDE 2.0+** – Program only the MCU using the beloved Arduino IDE.



Remote Procedure Call (RPC)

A built-in RPC library (i.e., Arduino Bridge) brings together the MPU running Linux and the microcontroller so you can create powerful and responsive applications in both worlds.

# USB-C Power Supply (65W)

The Arduino® USB-C Power Supply (65W) is a compact wall adapter for USB-C devices that support USB Power Delivery (PD). Recommended as the power source for the Arduino® VENTUNO™ Q, it features a foldable plug for easy transport and interchangeable EU and UK plugs. A USB-C to jack adapter (20 VDC X 3A) is also included for devices with a DC barrel jack input.

[Buy now](https://store.arduino.cc/products/usb-c-power-supply-65w)

## Downloadable resources

[Datasheet](/resources/datasheets/TPX00256-datasheet.pdf)

Features

Tech Specs

Suggested Libraries

The Arduino® USB-C Power Supply (65W) delivers up to 65 W to USB-C devices through the USB Power Delivery (PD) protocol, across five voltage profiles (5, 9, 12, 15, and 20 VDC), automatically negotiating the optimal output for the connected device. It is the recommended power source for the Arduino® VENTUNO™ Q board, and features a foldable plug with interchangeable EU and UK options.

Power Output

Five voltage profiles: 5, 9, 12, 15, and 20 VDC, with a maximum output of 65 W.

USB Power Delivery 3.0

USB PD 3.0 support for automatic voltage and current negotiation.

Regional Plugs

Integrated foldable US plug, plus interchangeable EU and UK plugs that swap without tools.

Safety Protection

Over-current, short-circuit, and over-voltage protection with automatic recovery.

# USB-C Power Supply (45W)

The Arduino® USB-C Power Supply (45W) is a compact, interchangeable plug adapter for USB-C devices supporting USB Power Delivery (PD). The 45 W multi-voltage power adapter provides intelligent power delivery across five voltage profiles (5 V, 9 V, 12 V, 15 V, 20 V), negotiating the optimal charging parameters for connected devices. With interchangeable regional plugs (EU, UK, US, AU) and broad safety certifications, it provides a universal power solution for development, prototyping, and deployment scenarios worldwide.

[Buy now](https://store.arduino.cc/products/usb-c-power-supply)

# USB-C Hub (8 in 1)

The Arduino® USB-C Hub (8 in 1) is a compact multiport adapter that expands a single USB-C port into eight functional interfaces, including power delivery, USB data ports, HDMI video output, Ethernet connectivity, and SD/TF card readers. With its plug-and-play design and broad OS compatibility, it provides I/O expansion for USB-C devices in development, prototyping, and deployment scenarios.

[Buy now](https://store.arduino.cc/products/usb-c-hub)

## Downloadable resources

[Datasheet](/resources/datasheets/TPX00241-datasheet.pdf)

Features

Tech Specs

Suggested Libraries

The **Arduino® USB-C Hub (8 in 1)** expands a single USB-C port into eight functional interfaces. The compact hub provides power delivery, USB data ports, HDMI video output, Ethernet connectivity, and card readers.

Eight Ports

USB-C PD (65 W), USB-C Data, USB-A 3.0 (5 Gbps), USB-A 2.0, HDMI (4K @ 30 Hz), RJ45 Ethernet (100 Mbps), SD card reader, and TF card reader.

Video Output

HDMI output supports up to 4K resolution (3840 × 2160) at 30 Hz with audio pass-through.

Power Delivery

USB-C PD port supports up to 65 W power delivery with pass-through to connected devices.

Network Connectivity

RJ45 Ethernet port for wired network connection (10/100 Mbps).

Card Readers

SD and TF (microSD) card readers support UHS-I and UHS-II formats. Both readers can be used simultaneously.

# VENTUNO Q

The Arduino VENTUNO Q is the edge AI computer that redefines what is possible at the edge, serving as the definitive powerhouse for AI and robotics applications. At its core lies a revolutionary Dual-Brain architecture: the robust Qualcomm Dragonwing™ IQ8 delivers up to 40 dense TOPS of AI compute for advanced computer vision and local LLMs, while the dedicated STM32H5 Microcontroller ensures the low-latency precision required for complex motor control and robotics.

The **Arduino® VENTUNO™ Q** integrates the Qualcomm® Dragonwing™ IQ8 (QCS8275) Microprocessor (MPU), running a full Ubuntu Linux environment (with Debian support coming soon), with the STMicroelectronics® STM32H5F5 Microcontroller (MCU) built on Arm® Cortex®-M33 architecture. This dual-architecture platform brings together Linux and microcontroller worlds through a built-in RPC library, so you can create powerful, responsive applications in one seamless workflow with Arduino App Lab.

Arduino App Lab combines Arduino sketches, Python scripts, and AI models into ready-to-run apps. The board features integrated Wi-Fi® 6 connectivity for fast, reliable data transfer, alongside a comprehensive suite of built-in connectors, including high-speed USB 3.0, HDMI, 2.5 Gb Ethernet, and expandable NVMe Gen.4 storage.

Advanced AI at the Edge

Run powerful AI Models securely on-device with the 40 dense TOPS NPU:

  * **Local LLM & VLM:** Low-latency reasoning without cloud constraints.
  * **Speech-to-Text & Text-to-Speech:** Two-way voice interaction with local transcription.
  * **Object Detection:** Classify and track objects in complex scenes for advanced machine vision and automation.



Qualcomm Dragonwing™ IQ8

Includes the powerful Qualcomm Dragonwing™ IQ8 (QCS8275) processor featuring:

  * Octa-core Arm® Cortex®
  * Adreno GPU/VPU: Arm® Cortex® A623 at 877 MHz
  * Hexagon Tensor AI Processor (NPU): up to 40 dense TOPS
  * Qualcomm Spectra 692 ISP



[Overview](https://www.qualcomm.com/internet-of-things/products/iq8-series/iq-8275)

STM32H5F5 Arm® Cortex®-M33 32-bit MCU

The VENTUNO Q integrates the STM32H5F5 microcontroller featuring:

  * Arm® Cortex®-M33 at 250 MHz
  * 4 MB flash memory
  * 1.5 MB RAM



Comprehensive Connectivity

The VENTUNO Q ensures you remain connected and ready to execute with a comprehensive suite of built-in connectors:

  * 1x 2.5Gbit RJ45 Ethernet
  * 1x HDMI muxed with MIPI DSI
  * 1x USB-C port with host/device role switching and video output
  * 2x USB 3.0 Type A
  * Wi-Fi® 6 2.4/5/6 GHz and Bluetooth® 5.3



Seamless Expandability

Unlock unprecedented hardware possibilities natively:

  * **UNO Shield Headers:** Compatible with the vast library of Arduino UNO Shields.
  * **Qwiic Connector:** Instant access to Modulino® nodes and sensors without soldering.
  * **M.2 Connector:** NVMe Gen.4 external storage expansion.
  * **Carrier Headers (JMEDIA, JMISC, JOMEGA):** Bridging high-speed cameras, displays, audio, or precise motor control.
  * **40-Pin Header:** Compatible with standard Raspberry Pi HATs to tap into a massive ecosystem of SBC accessories.



Arduino App Lab

The converging point of development across NPU, CPU, GPU, and MCU platforms, uniting embedded (sketch) programming, Linux development, and edge AI.

  * **Standalone Mode:** Runs directly on VENTUNO Q, just plug in a monitor, keyboard, and mouse.
  * **PC-Connected Mode:** Connect via USB-C or network and run Arduino App Lab on your PC.
  * **Networked Mode:** Run VENTUNO Q headless, no display or keyboard needed. Access remotely over Wi-Fi® or Ethernet.

The **UNO Breakout Carrier** expands the capabilities of the Arduino UNO Q by providing complete, direct access to relevant signal available on the JMEDIA and JMISC high-speed connectors. Ideal for advanced prototyping, testing, and integration work, the UNO Breakout Carrier safely exposes audio, I2C, SPI, UART, PWM, power rails, and control signals to standard headers. It eliminates the need for complex adapters or soldering, making it the ultimate tool for accelerating hardware validation and simplifying troubleshooting.

Standard 2.54 mm Male Headers

Connect the UNO Q to custom circuits, measurement equipment, or third-party modules effortlessly. The clearly labeled dual 2x20 header rows allow for fast, reliable wiring without the need for complex adapters or soldering.

Direct High-Speed Signal Access

Unlocks the full potential of the UNO Q's advanced interfaces by safely routing Audio, I2C, SPI, UART, PWM, PSSI, and GPIO signals directly to your custom peripherals and interface boards. 

Advanced Audio Prototyping

Fully exposes crucial multimedia interfaces—including HP OUT, LINE OUT, MIC IN, and EAR OUT—making it the perfect platform for developing, integrating, and testing smart audio and complex multimedia systems.

Simplified Hardware Debugging

Designed for R&D and test engineers, the accessible layout allows for quick attachment of oscilloscopes and logic analyzers. It enables rapid signal integrity testing and compliance validation across all critical communication buses.

The Arduino® USB-C Cable (24-pin) is a USB-C to USB-C cable featuring full 24-pin connectivity for complete functionality, including data transfer, video output, and power delivery. This 1-meter braided cable supports USB 3.0 data speeds up to 5 Gbps, power delivery up to 60 W (20 V / 3 A), and DisplayPort Alt Mode for video transmission. Designed for use with USB-C devices requiring full-featured connectivity, it provides reliable performance for development, prototyping, and deployment scenarios.

# UNO R4 WiFi

The Arduino UNO R4 WiFi is designed around the 32-bit microcontroller RA4M1 from [Renesas](https://www.renesas.com/us/en) while also featuring a ESP32 module for Wi-Fi® and Bluetooth® connectivity. Its distinctive 12x8 LED matrix makes it possible to prototype visuals directly on the board, and with a Qwiic connector, you can create projects plug-and-play style.
